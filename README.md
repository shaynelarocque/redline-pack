# REDLINE resource pack

Builds of the resource pack for **REDLINE**, HCF Revival's duel server: the HUD, menus, motion, sound and music.

You don't need to download anything here. The server sends the pack when you join and checks its SHA-1, so
you always get the build it was made for.

Every build lives in the [`packs` release](../../releases/tag/packs) as `redline-<first 12 of its sha1>.zip`.
